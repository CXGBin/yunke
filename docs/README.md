## 多租户方案速览

```
方案：共享数据库 + TenantId 字段（不使用数据库隔离）

所有业务表均含 TenantId (= Organization.Id)
ORM层(SqlSugar)全局过滤器自动注入 WHERE TenantId = @val
平台管理员移除过滤器 → 跨租户汇总统计
与财务系统(单租户)不同，从架构层面原生多租户支持
```
