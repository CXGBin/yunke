## 七、问题汇总与修复优先级

### P1 - 必须修复（10个）

1. **EvaluationService** - 7个方法在TenantId=0（平台管理员）时500错误
   - 根因：平台管理员角色查询未特殊处理
   - 修复：在Service层检查Role==1时跳过TenantId过滤或返回空结果

2. **SettlementService.GetExportAsync** - 空数据500
   - 根因：GroupBy查询在空数据集时异常
   - 修复：增加空数据检查或Try-Catch

3. **SettlementService.GetSummaryAsync** - 500错误
   - 根因：同上，GroupBy查询异常

4. **InvitationService** - Page/Validate 500
   - 根因：TenantId=0查询异常

### P2 - 建议修复（1个）

5. **NotificationController.Template Page** - 路由405
   - 检查HttpGet装饰器

### INFO - 正常业务异常（3个）

- 课程/结算规则查询不存在的ID → 正常BizException
- 机构绑定详情未绑定 → 正常BizException
