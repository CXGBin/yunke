# 云科智教 — 课程管理平台完整需求文档

> **版本**：v1.2（初稿待审阅）
> **日期**：2026-06-16
> **定位**：教育SaaS，多租户共享库架构
> **技术栈**：原生小程序 + React Antd Pro PC端 + .NET 8 + MSSQL 2019

---

## 一、项目概述

云科智教是面向教育培训机构的课程全生命周期管理SaaS平台。小程序端供学生/家长使用，PC管理端供教师/机构管理员/平台管理员使用，覆盖课程发布、选课、排课、签到、评价、数据分析、课程费结算等核心业务。

---

## 二、角色体系

### 2.1 四级树形结构

```
平台方（SaaS运营方）
  └── 教育机构方（租户）
        └── 校区（物理分支）
              ├── 教师（归属机构+主校区，可跨校区授课）
              ├── 学生（归属校区）
              └── 家长（独立账号，多对多关联学生）
```

### 2.2 角色定义

| 角色 | 端 | 核心职责 |
|------|-----|---------|
| **平台管理员** | PC | 管理所有机构/校区、全局数据监控、平台配置、机构年费套餐设置 |
| **机构管理员** | PC | 管理本机构校区/教师/课程/排课/审核评价/查看报表,发布课程，发布课程套餐 |
| **教师** | 小程序 | 课程排课（需要有权限），查看排课、课堂签到、查看评价 |
| **学生** | 小程序 | 选课，课时评价、查看课表、查看历史上课记录 |
| **家长** | 小程序 | 关注孩子课程、查看出勤、接收通知、代缴费用 |

### 2.3 权限边界

| 维度 | 平台管理员 | 机构管理员 | 教师 | 学生/家长 |
|------|:---------:|:---------:|:----:|:---------:|
| 数据可见范围 | 全平台 | 本机构所有校区 | 本校区 | 本校区（自己） |
| 管理机构/校区 | ✅ 全平台 | ✅ 本机构 | ❌ | ❌ |
| 课程管理 | ✅ 全平台 | ✅ 本机构 | ✅ 自己授课 | ❌ |
| 查看报表 | 全平台汇总 | 本机构汇总 | 自己教学数据 | 个人/孩子数据 |
| 平台配置 | ✅ | ❌ | ❌ | ❌ |

## 三、技术架构

| 层级 | 技术 | 说明 |
|------|------|------|
| 小程序端 | 微信原生 | 支持主题切换，适配不同机构品牌 |
| PC端 | Antd Pro (React) | 多页签后台 |
| 接口端 | .NET 8 Web API | RESTful，JWT，SqlSugar ORM |
| 数据库 | MSSQL 2019 | 共享库 + TenantId 字段隔离 |
| 缓存 | Redis（可选） | Token、验证码、热数据 |

### 3.1 多租户方案

- 所有业务表包含 `TenantId`（= 机构ID）
- SqlSugar 全局过滤器自动注入 `WHERE TenantId = @val`
- 平台管理员可移除过滤器查看全局数据（跨租户汇总）
- 机构内通过 `CampusId` 进一步隔离

### 3.2 认证方案

- 小程序：微信登录 → 绑定手机号 → JWT Token（7天有效期）
- PC端：账号密码 → JWT Token
